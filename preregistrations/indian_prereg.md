# Indian mixed-traffic scenarios — PRE-REGISTRATION (Sonnet, 2026-11-09, written before any scenario run)

Honesty note: no Indian car-following dataset is used. Scenarios are STYLIZED disturbances injected into real OpenACC lead trajectories; parameters below are assumptions (to be justified/cited in the paper), not measurements. Results say how controllers respond to such disturbances, not that they reproduce Indian traffic statistics.

Base windows: the 90 pre-registered V2V TEST windows (results/v2v_windows.csv, role=test); for compute, the 45 rows with even position (0,2,4,...) of that role in file order. Plant: eta 0.65, cap 35 kW, fade<3 m/s. All controller weights/gains frozen from earlier tuning (ACC .4/1.0, CACC .25/1.0, SMC .3/.5/2.0, MPC frozen weights, V2V-LGBM + EMA alpha .5 beta .5). Randomness: numpy seed = 7000 + 100*scenario + window row.

S1 SPEED BREAKERS (static map feature). Breaker cap speed v_b = 4.2 m/s (15 km/h). First breaker at x = U(150,250) m from the ego start, then spacing U(250,600) m. Lead profile = min(recorded lead speed, kinematic cap: approach decel 2.0 m/s^2, departure accel 1.0 m/s^2). Ego start x=0, lead starts at the initial gap.
 Arms: ACC, CACC, SMC, MPC-const, **ACC-map** (ACC with a position-based speed limit: v_des(x)=sqrt(v_b^2+2*1.5*(x_b-x)), a=min(a_acc, 1.0*(v_des-v)); gives the map to the reactive baseline so information is not credited to MPC only), **MPC-map** (MPC-const preview + soft speed-cap constraint v<=v_b at the predicted breaker crossing step, slack weight 20 Wh per m/s), MPC-V2V-ML (no map), MPC-oracle (lead known, no map).
 Metrics: Wh/km (KE-adj), mean/max ego speed excess over v_b at crossing, share of crossings > v_b+1.0 m/s, jerk RMS, unsafe windows (shortfall > 0.5 m).
 PRIMARY RULE: MPC-map median Wh/km >= 1.0% below ACC-map AND mean crossing excess <= ACC-map's + 0.3 m/s AND unsafe windows <= ACC-map's. Wilcoxon p<0.05. Otherwise reported as not supported.
S2 CUT-INS. First cut-in at t=15 s + Exp(35 s) gaps (until 110 s). At a cut-in the gap becomes g_c=U(8,15) m if the current gap is larger; the new lead runs at lead_speed - Delta*exp(-(t-t_c)/T), Delta=U(2,5) m/s, T=U(8,14) s. V2V predecessor signal is NOT modified (cut-ins invisible to V2V; conservative for V2V). Arms: ACC, CACC, SMC, MPC-const, MPC-V2V-ML, MPC-oracle (knows modified lead). No pass/fail rule; report medians, shortfalls, jerk.
S3 STOP-GO HARD BRAKING. Events from t=15 s with Exp(35 s) gaps: lead brakes at U(2.5,3.5) m/s^2 to v_min=U(0,0.3)*current speed, holds 3 s, accelerates at 1.5 m/s^2 back to the recorded profile. V2V signal not modified. Same arms as S2. No pass/fail; report medians, shortfalls, jerk.
Reporting: per scenario table (Wh/km, median % vs ACC (ACC-map in S1), unsafe windows with max shortfall, jerk, crossing excess in S1); all arms reported, none dropped. Limitation to state: injected events independent of the predecessor => V2V gives no early warning; map preview is exact for static breakers.
